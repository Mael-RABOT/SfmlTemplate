# SFML Template Project

This project is a simple template for creating applications using the SFML (Simple and Fast Multimedia Library). It includes basic wrapping of components, custom exception handling, and window configuration for ease of use and extensibility.  

---

## Features

- SFML Integration: Pre-configured setup for SFML.
- Component Wrapping: Basic wrappers for SFML components to simplify usage.
- Custom Exception Handling: Centralized exception management for better debugging and error handling.
- Window Configuration: Easily configurable window settings (e.g., resolution, title, framerate).

---

## Requirements

- C++17 or later
- SFML 2.5 or later
- A C++ compiler (e.g., GCC, Clang, or MSVC) - The makefile uses g++
- Make (for building the project)

---

## Setup and Build

### Clone the repository:  

```sh
git clone git@github.com:Mael-RABOT/SfmlTemplate.git &&
cd SfmlTemplate
```

### Build the project:

```sh
make build
```

### Run the application:  

```sh
./main
```

---

## Usage

This template provides a starting point for SFML-based projects. You can extend the provided wrappers and customize the window configuration to suit your needs.
